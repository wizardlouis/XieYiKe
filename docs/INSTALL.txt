歇一刻 · XieYiKe 1.0.1
忙的时候记得歇，晚的时候记得停。

系统要求：macOS 12 或更新版本，支持 Apple 芯片和 Intel Mac。

安装
1. 打开 DMG，将“歇一刻”拖到 Applications（应用程序）文件夹。
2. 从“应用程序”打开。顶部菜单栏会出现闹钟图标；默认没有 Dock 图标。
3. 点击悬浮界面的齿轮设置时长和提醒文字，再点击播放开始。

首次打开
本版本使用 ad-hoc 本地签名，尚未使用 Apple Developer ID 签名或 Apple 公证。
如果 macOS 阻止打开，请先确认来源是下面的官方仓库。
在你信任该应用的情况下，按 Apple 官方说明，从“系统设置 → 隐私与安全性”查看“仍要打开”。
不要关闭 Gatekeeper 或系统安全保护。公司管理的电脑可能需要管理员处理。
Apple 说明：https://support.apple.com/102445

操作
播放／暂停：切换倒计时状态。
回转箭头：恢复设定时长。
齿轮：设置小时、分钟、秒、提醒文字、字号和颜色。
锁：锁定位置，只保留解锁按钮，时间区域点击穿透。
到时提醒：每台显示器中央都会出现文字；点击任一个“关闭提醒”一起收起。
退出：点击菜单栏闹钟图标，选择“退出歇一刻”。

注意
• 修改设定时长会重置倒计时。
• 电脑睡眠时不会被唤醒，唤醒后会显示已到时的提醒。
• 应用不能覆盖系统锁屏等安全界面。
• 这是 Mac 文字提醒工具，不播放铃声，不自动循环，不包含手机端。
• 所有偏好保存在本机；无需账号、联网或敏感权限。

更新：先退出旧版本，再替换“应用程序”中的应用。原设置会保留。
卸载：退出后将“歇一刻.app”移到废纸篓即可。
